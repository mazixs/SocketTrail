# Изменения

## v0.1.0 - 2026-09-20

Первый релиз. Linux.

- Дерево процессов с автообновлением, распознавание Proton и Wine, выбор
  процесса вместе со всеми потомками.
- История соединений по процессу: домен, IP, порт, протокол, состояние,
  владелец сети (ASN), объем трафика. Закрытые соединения остаются в списке.
- Два источника данных: опрос `/proc/net/{tcp,tcp6,udp,udp6}` каждые 200 мс и
  разбор потока pcapng от `dumpcap`. Второй ловит соединения короче интервала
  опроса и дает домены из DNS-ответов и SNI.
- Порты только настоящие: из таблицы сокетов или из заголовка пакета, без
  подстановок по типу службы.
- Имена адресов из четырех источников (SNI, DNS, PTR через resolvectl, подписи
  служебных адресов) с дисковым кешем `~/.cache/sockettrail/names.json`.
- Запись дампа в `~/SocketTrail/<процесс>-<дата>.pcapng` с картой соединений
  в `.json` рядом, по желанию с BPF-фильтром по адресам процесса.
- Автономный HTML-отчет, сводка по адресам, копирование строки и таблицы,
  изменяемые колонки, темная и светлая темы.
- Установка без root: `./install.sh` кладет бинарь в `~/.local/bin` и ярлык в
  меню приложений; фоновый сбор через user-юнит systemd.
